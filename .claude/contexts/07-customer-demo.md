# 客户 Demo

## 当前状态与入口

STEP-SIM-003 已实现。本机进程级断网彩排通过。运行入口见 [Demo 说明](../../Demo/README.md)，证据见 [开发样本](../../Demo/evidence/01-development.md)、[历史库和联调](../../Demo/evidence/02-integration.md)及[冻结彩排](../../Demo/evidence/03-rehearsal.md)。正式替代证据、试点和平台规划沿用 STEP-SIM-002。

## 输入、输出与设计约束

- 输入为一个上传 STEP 和同一零件族的历史库。现有 SQLite 含 37 件演示安装板，保存源文件、元数据、GLB 和网格。查询以独立目录存档。首版处理闭合单实体。
- 技术路线为本地 Python/FastAPI 后台任务、OCCT、HTML/Three.js 与 GLB。接口以查询编号关联进度、候选、模型和差异。前端依赖本地提供，可断网运行。
- 输出最多 5 个通过对齐检查的几何候选，另列待复核。两模型联动并排。坐标可靠时提供原尺度双色叠加，使用同一对齐结果按各自场景坐标换算。结果页须保留几何用途说明和自制样例标识。
- 任一查询的精排都按模型几何运行多初值对齐。去重容差严于歧义阈值，比较相对旋转角和同一旧件采样点质心的位移。参考点只用于彩排核验。安装板的孔区读数取本次双向网格采样的区域最大值，页面和验收共用，采样不足明示。
- 冻结库快照、版本和参数后彩排。找回分母包含所有预登记目标查询，解析或库侧导入失败、目标仅进待复核均计为未找回。错对齐、展示与找回分别记录。
- `Demo` 分支携带 37 件自制演示库快照、样本和可复核证据。上传记录与本地重建库保存在 Git 忽略的运行目录。冻结输入按原字节检出。

## 已核实与待验证

- 开发集验证五个自制 STEP。同件通过三个非共线参考点及 130 mm 边长检查，孔区值 5.995 mm，歧义件 4 个合格姿态。仅用开发集比较 K=4/5/8，冻结 K=5。
- 独立彩排前五找回 2/2，均第 1。孔区显示 4.996 mm，双向有效点 736/737。歧义样本 5 个合格姿态，相对旋转达 180°。有效上传至结果 14.59–19.25 s，选中目标至可操作约 0.11–0.12 s。浏览器外网探针失败且页面外连为 0。
- 待验证真实客户 STEP 的单位、导入、对齐与耗时。现场整机断网复跑尚待执行。冻结参数与失败复跑记录见彩排证据。
