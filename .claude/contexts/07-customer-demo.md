# 客户 Demo

## 当前状态与入口

STEP-SIM-003 已实现。Windows Studio 0.3.1 安装与运行入口见 [Demo 说明](../../Demo/README.md)，证据见 [冻结彩排](../../Demo/evidence/03-rehearsal.md)、[中文安装与相似度核验](../../Demo/evidence/05-studio-similarity.md)和[评分详情核验](../../Demo/evidence/06-score-details.md)。正式替代证据、试点和平台规划沿用 STEP-SIM-002。

## 输入、输出与设计约束

- 输入为一个上传 STEP 和同一零件族的历史库。现有 SQLite 含 37 件演示安装板，保存源文件、元数据、GLB 和网格。查询以独立目录存档。首版处理闭合单实体。
- 技术路线为本地 Python/FastAPI 后台任务、OCCT、HTML/Three.js 与 GLB。接口以查询编号关联进度、候选、模型和差异。前端依赖本地提供，可断网运行。
- 输出最多 5 个通过对齐检查的几何候选，另列待复核。两模型联动并排。坐标可靠时提供原尺度双色叠加，使用同一对齐结果按各自场景坐标换算。结果页须保留几何用途说明和自制样例标识。
- 任一查询的精排都按模型几何运行多初值对齐。去重容差严于歧义阈值，比较相对旋转角和同一旧件采样点质心的位移。参考点只用于彩排核验。安装板的孔区读数取本次双向网格采样的区域最大值，页面和验收共用，采样不足明示。
- 冻结库快照、版本和参数后彩排。找回分母包含所有预登记目标查询，解析或库侧导入失败、目标仅进待复核均计为未找回。错对齐、展示与找回分别记录。
- `Demo` 分支携带 37 件自制演示库快照、样本和可复核证据。上传记录与本地重建库保存在 Git 忽略的运行目录。冻结输入按原字节检出。
- 安装版为 PyInstaller 目录式应用，由 Inno Setup 分发。WebView2 运行时随包提供。Studio 窗口管理 FastAPI 回环服务生命周期，安装目录中的 `Data/Base` 通过增量索引参与检索。成功结果按查询编号归档到 `Data/History`，包括原始 STEP、结果和比较时的预览模型。居中进度框在归档成功后达到 100%。
- 源码、网页和安装配置在 `Demo/src`。用 `Demo/Tools/Compile.bat` 生成 Studio.exe，用 `Demo/Tools/Package.bat` 生成简体中文安装包。
- 每条有表面测量结果的候选显示几何相似度，分值来源为表面 RMS 40、P95 20、最大偏差 10、尺寸 20、面积 5、体积 5。新结果保存分项和总分。评分与现行双向 RMS 排序及待复核状态并列。
- 分数旁「详情」按钮打开该条结果的六项实测误差、实得分、满分和零分阈值。待复核时同时展示对齐原因，关闭后回到当前三维视图。

## 已核实与待验证

- 开发集验证五个自制 STEP。同件通过三个非共线参考点及 130 mm 边长检查，孔区值 5.995 mm，歧义件 4 个合格姿态。仅用开发集比较 K=4/5/8，冻结 K=5。
- 独立彩排前五找回 2/2，均第 1。孔区显示 4.996 mm，双向有效点 736/737。歧义样本 5 个合格姿态，相对旋转达 180°。有效上传至结果 14.59–19.25 s，选中目标至可操作约 0.11–0.12 s。浏览器外网探针失败且页面外连为 0。
- 已验证安装至中文路径、覆盖安装保留数据、内嵌界面启停、中文基础件入库、完成归档、失败提示与重试。待验证真实客户 STEP 和其他目标 Windows 环境，包括缺少 WebView2 时的安装流程及整机断网。
- 0.3.1 实际安装后已验证评分详情：孔位查询中 SHOW-H01 为 81.6 分，RMS 0.588 mm 得 28.24/40；查看其他候选或待复核详情后，原选择和三维视图保持不变。对称件详情显示对齐原因，仍仅能并排查看。原有同件、孔位、对齐歧义、损坏文件及重试回归通过。安装包及证据见 [评分详情核验](../../Demo/evidence/06-score-details.md)。
- 0.3.0 的独立评分核验记录保留在 [中文安装与评分核验](../../Demo/evidence/05-studio-similarity.md)：同件 100.0 分、孔位改动 81.6 分、对称件 100.0 分并待复核；旧 JSON 只读评分保持原哈希。该记录对应 0.3.0 安装包。
