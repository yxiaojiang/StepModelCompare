# 模块记忆索引

此目录保存按模块拆分的当前态，方便处理某一模块时只加载对应记忆。跨模块共识见 ../ProjectMemory.md；当前项目状态见 ../SessionBrief.md 和 ../Plan.md；完整方案与决策见 Docs/ 和 PlanDocs/。

## 使用规则

1. 开始任务时先读本索引，根据任务范围打开对应模块文件，不要整目录读取。
2. 一个模块上下文只记录该模块当前职责、输入/输出、关键约束、已验证事实、待验证事项和相关文件入口；不要复制整段实施方案。
3. 以下分组来自已采纳方案的工作内容，是记忆导航，不代表最终软件架构已经确定。模块真正启动或边界明确后，再建立或更新对应文件。
4. 模块间共通的决定放在 ProjectMemory；模块内部的阶段进展放在相应上下文；已关闭内容从当前态移除或归档，并保留追溯链接。
5. 新增模块文件后，在本索引登记简明范围、当前状态和入口文件。
6. 表中是建议文件名而非现存文件。文件尚未建立时，不要尝试读取空占位内容；模块开始后再创建。
