# 模块上下文：多企业 STEP 相似度对比与检索平台（STEP-SIM-004）

## 模块职责
面向多企业服务端部署的正式 STEP 相似度对比与检索系统（规划目录 `Platform/`），整合：
1. 可配置 `D1–D7` 多维特征引擎 + 独立安全门禁 + 动态有效权重上界剪枝；
2. 注册登录、企业与邀请码、无邀请码 5 次并发安全限额、跨企业 SQL 强隔离、五态待审入库台账与规则配置后台；
3. Three.js 三维图形化对比工作台与客户端双 API（批量上传待审 + 单件 STP 对比）。

## 输入 / 输出
- **输入**：客户端或服务端上传的 `.stp`/`.step` 零件模型、企业/用户/邀请码凭证、服务端 `D1–D7` 百分比与缺项规则配置。
- **输出**：结构化 `模型特征值` 与 GLB 预览缓存、百分制综合相似度与分项有效权重得分拆解、「待复核」分流结果、6 项必记模型台账、Web 三维并排/双色叠加视图及客户端结构化 JSON 响应。

## 关键工程约束（已采纳，实施不可违背）
- **维度与门禁**：`D1` 基本信息、`D2` 体积（区分单/多闭合实体与开壳）、`D3` AP242 PMI、`D4` 曲面（面积+类型占比+共轴共面合并面数）、`D5` 空间对齐表面吻合度、`D6` 主轴 OBB、`D7` 局部孔系拓扑（可独立赋权或承接双无 PMI 时的 D3）；左右手性/对称歧义为不占百分比的独立门禁。
- **缺项与剪枝**：区分“双方缺失”与“单方缺失（显式标未核实，默认 0 分保守计分）”，$V(q,m)=\emptyset$ 禁除零转「特征不足/待复核」；上界剪枝按重分配后有效权重 $W'_{\text{D5}}(q,m)$ 计算 $U(q,m)$，区分 `exact_pruned` 与 `truncated_by_k`（截断漏检留分母）。
- **并发与安全**：无邀请码 5 次限额采用 `used_count + in_flight_count < 5` 短事务预占 + 成功实扣/失败回滚 + 超时回收器（回收阈值严于 `排队上限 + OCCT 硬超时`）；客户端 API 严禁 URL Query 传密码、日志脱敏、防爆破锁定；OCCT 解析运行在独立子进程（硬超时/内存/面片熔断）；入库五态 `PENDING → INDEXING → APPROVED / PARSE_FAILED` 及 `REJECTED`，同企重复 MD5 幂等跳过；Web 工作台固定显示工程边界提示。

## 已验证事实
- `Demo/.venv` 中 `OCP` 已实测包含 `STEPCAFControl_Reader`、全部 `XCAFDoc_*Tool` 与 `BRepAdaptor_Surface`。
- `Demo/src/` 已验证毫米统一、24 初值右手系 ICP、AABB 双向距离、GLB 矩阵 $C_{\text{新}} T C_{\text{旧}}^{-1}$ 及对称歧义分流。
- 商务报价 `92 人/天 × ¥2,895 = ¥266,340` Excel 已清除 `N14` 脏数据并写入全部 19 处公式缓存值。

## 待验证事项（阶段 1 冻结）
- 客户 20–50 件真实 `.stp` 的协议/PMI/材料/多实体与开壳分布；
- 单方缺失默认策略、待审审核角色粒度（系统管理员 vs 企业管理员）、注册防刷门槛、公共演示库来源、规则作用域、客户端 Top-N/同步异步契约及目标服务器环境。
