## 建议决定

### 1. 相似度评判标准设计：统一 `D1–D7` 可赋权维度池 + 独立安全门禁

系统保留相似度评分用于**候选检索、接近度量化排序与三维差异辅助检查**的定位，不将其单独等同于工程直接替代放行结论。将客户提出的 4 项标准与我方补充的 3 个量化几何维度统一固定为 **`D1–D7` 共 7 个可独立设置百分比权重的维度**，并将**「左右手性与对称姿态歧义检验」**单列为独立于百分比加权之外的强制安全门禁（与 [STEP模型相似度评判逻辑与判断标准说明.md](../Docs/STEP模型相似度评判逻辑与判断标准说明.md) 第 3 节严格一致）：

| 维度编号与名称 | 来源与定位 | 潜在工程/数据风险 | 拟采用的量化与纠偏规则 |

### 2. 百分比动态配置、缺项语义与有效权重上界剪枝机制

1. **标准化子分与任意百分比配比**：
   每个可赋权维度 $i \in \{\text{D1}\dots\text{D7}\}$ 按各自零分误差阈值 $\tau_i$ 独立输出标准百分制子分 $s_i(q, m) = 100 \times \max(0, 1 - e_i / \tau_i) \in [0, 100]$。服务端规则引擎配置基础百分比权重 $W_i \in [0, 100\%]$，保存时强制校验启用项 $\sum_{i=1}^{7} W_i = 100\%$（设为 `0%` 即停用该项；若全部基础几何维度 D4/D5/D6/D7 均为 `0%`，界面弹出无几何兜底风险告警）。支持保存多套项目规则模板，每次对比结果绑定当时生效的规则版本号与权重快照。

2. **区分“双方缺失”与“单方缺失”，补齐 $V(q, m) = \emptyset$ 防除零保护**：
   - **双方均缺失**（如查询件 $q$ 与候选件 $m$ 均无材料属性、均无 AP242 PMI 或均为开壳无体积）：按服务端规则将该项移出本次有效维度集合 $V(q, m)$ 并按比例重分配权重（对 D3 亦可配置将权重转入 D7 孔系特征），详情注明「双方未携带，已按规则重分配/几何替代」。
   - **单方缺失**（如查询件明确携带材料或 PMI 公差，而候选件缺失对应字段，或反之）：**严禁默认静默抹除权重**（防止未填材料的未知旧件得分高于已填近似材料的旧件）！该维度保留在 $V(q, m)$ 内，评分详情强制高亮标记**「单方缺失（未核实）」**，由规则配置显式三选一（默认定为**「按 0 分保守计分」**，可选「按固定中性折算分（如 50 分）计」或「显式授权重分配」；默认策略在阶段 1 与客户签认冻结）。
   - **有效权重与 $V(q, m) = \emptyset$ 防除零兜底**：
     - 当 $V(q, m) \neq \emptyset$（即 $\sum_{j \in V(q, m)} W_j > 0$）时，计算重分配后的有效百分比权重（若 D3 转入 D7，先令 $\tilde{W}_{\text{D7}} = W_{\text{D7}} + W_{\text{D3}}$）：
       $$W'_i(q, m) = 100 \times \frac{\tilde{W}_i}{\sum_{j \in V(q, m)} \tilde{W}_j}, \qquad S_{\text{total}}(q, m) = \sum_{i \in V(q, m)} \frac{W'_i(q, m)}{100} \cdot s_i(q, m)$$
     - 当管理员仅启用了可选条件维度且遇到某对模型所有启用项均缺失导致 **$V(q, m) = \emptyset$（$\sum_{j \in V(q,m)} \tilde{W}_j = 0$）**时，**禁止执行 `0/0` 归一化除零**，直接跳过总分计算，将该候选状态标记为**「特征不足/待复核」**（不计入可靠候选前五，详情列明各缺失原因）。

3. **「模型特征值」持久化与改规则免重解析**：
   模型经服务端人工确认入库时，异步计算并持久化存储结构化 `模型特征值`（含提取算法版本号、基本信息字典、精确体积与闭合/实体数状态、PMI 特征与 D7 孔系特征向量、曲面面积/类型占比/合并面数、OBB 尺寸与主轴、采样点云及 GLB 预览）。后续管理员修改各维度百分比或零分阈值时，**历史已入库模型无需重新解析 STEP 原文件**。

4. **按有效权重的上界剪枝与“精确终止 vs 上限 $K$ 截断”透明化**：
   - 若某候选的有效表面权重 $W'_{\text{D5}}(q, m) = 0$（未启用 D5，或 $V(q,m)=\emptyset$ 已转待复核），直接由缓存的 `模型特征值` 得出精确结果，无需运行 ICP 精排；
   - 若启用 `D5`（$W'_{\text{D5}}(q, m) > 0$），先对可见库每件模型精确计算除 D5 外的有效加权实得分与**基于重分配后有效权重 $W'_{\text{D5}}(q, m)$ 的真实乐观总分上界**：
     $$S_{\text{other}}(q, m) = \sum_{i \in V(q, m)\setminus\{\text{D5}\}} \frac{W'_i(q, m)}{100} \cdot s_i(q, m), \qquad U(q, m) = S_{\text{other}}(q, m) + W'_{\text{D5}}(q, m)$$
     （即便缺项重分配使 $W'_{\text{D5}}(q, m) > W_{\text{D5}}$，$U(q, m)$ 仍严格等于该候选在 $s_{\text{D5}} = 100$ 时的真实最高可能总分，不会低估误剪。）
   - 候选按 $U(q, m)$ 降序（同分按 OBB/体积/面积几何接近度排序）依次送入多初值 ICP 精排，动态维护当前已通过对齐检查的前五名最低实得总分 $S_{(5)}$（不足 5 件时记 $S_{(5)} = -\infty$），并**严格区分两种停止模式**：
     1. **精确剪枝无漏检终止**：在触及精排件数上限 $K$ 之前，剩余未精排候选的最大上界已满足 $\max U(q, m) \le S_{(5)}$——此时数学上严格保证无任何潜在前五候选被漏检，诊断标记 `termination = "exact_pruned"`；
     2. **触及上限 $K$ 近似截断**：若为控制高并发响应延迟，在仍存在未精排候选满足 $U(q, m) > S_{(5)}$ 时达到服务端配置的精排上限 $K$ 而停止，则属于**受算力预算约束的近似截断（不声称无漏检）**，诊断日志显式记录 `termination = "truncated_by_k"` 及未测最大上界；在验收检索找回统计中，凡因此未进入前五的正例均归因记为**「粗排/预算截断漏出」**并保留在总分母中。

### 6. 建议验收口径与统计分母

| 验收维度 | 核对方法与统计分母（防静默跳过） |
| --- | --- |
| **可配置权重、缺项语义与防除零** | 配置至少 3 组不同权重（含“5 项各 20%”、“30%/10% 非均分”、“仅启用 D1/D3 且几何项为 0%”），免重解析核对：① 正常有效项下总分严格等于 $\sum (W'_i/100)s_i$（误差 $< 0.05$ 分）；② 单方缺失材料或 PMI 时详情强制显示「单方缺失（未核实）」并按选定策略计分；③ 当 $V(q,m) = \emptyset$ 时不抛除零异常，准确归入「特征不足/待复核」。 |
| **四类易误判难例行为** | 使用预登记测试集逐例核对：① **同件跨 CAD 重导出（面片数变化）**不因原始片数分裂跌出前五；② **双方无 AP242 PMI / 无材料的普通 STEP** 按所选重分配/D7 替代策略正常打分，不锁死 80 分也不白拿 20 分；③ **同体积异形件**在启用 D5 与 D6 后被有效拉开分差；④ **左右镜像件 / 旋转对称歧义件**不产生错误刚体叠加，歧义样本准确进入「待复核」且仅并排。 |
| **检索找回分母与截断归因** | 在客户提供的预登记测试查询集中，以**全部提交的预登记正例查询总数**为分母。查询解析失败、库侧 `PARSE_FAILED`、因触及精排上限 $K$ 被近似截断（`truncated_by_k`）未进前五、或目标仅落入「待复核」的记录**全部保留在分母中计为未命名前五**，并按“解析失败 / 粗排或预算截断漏出 / 精排掉出 / 待复核分流”四类分别报告计数。 |

## 建议顺序

按总工作量 **92 人/天**，投入 **2 名工程师双线协同**（算法/内核线 + 平台/前端线并行推进，总体日历周期约 **10–12 周**）分四阶段实施：

1. **阶段 1：客户样本盘点与安全/接口/规则契约冻结（约 1.5–2 周）**
   - 抽取客户代表性 `.stp` 样本实测闭合性、多实体/开壳比例、跨 CAD 面片特征、XDE 属性与 AP242 PMI 携带率；
   - 与客户签认冻结：`D1–D7` 默认百分比模板、**单方缺失默认计分策略**、**待审队列审核角色归属（系统管理员 vs 企业管理员）**、**无邀请码注册防刷方式**、客户端双 API 请求/响应契约（HTTPS Header/Body 鉴权、Top-N 数量、选中回传方式）及精排上限 $K$ 与子进程超时/内存熔断阈值。
   - **放行条件**：真实样本盘点报告完成，上述安全、缺项与接口契约经客户书面或会议纪要确认冻结。
2. **阶段 2：多维特征引擎升级与动态有效权重评分内核（约 3.5–4 周，双人协同，对应报价模块一 37 人/天）**
   - 扩充独立 OCCT Worker 子进程（含超时与内存/面片熔断）、单/多闭合实体与开壳判别、XDE 基本信息提取、AP242 PMI 解析、D7 孔系特征提取、共轴/共面逻辑合并及曲面类型面积分布计算；
   - 实现结构化 `模型特征值` 入库序列化、`D1–D7` 动态百分比打分器、单/双方缺失分离处理、$V=\emptyset$ 防除零兜底，以及基于 $W'_{\text{D5}}(q,m)$ 的上界剪枝与 $K$ 截断诊断；完成四类难例回归验证。
   - **放行条件**：改权重免重解析生效，上界剪枝数学一致性、$V=\emptyset$ 兜底及四类难例单测全部通过。
3. **阶段 3：多企业权限、五态待审台账与服务端规则后台（约 3–3.5 周，双人协同，与阶段 2 中后段并行，对应报价模块二 31 人/天）**
   - 实现注册防刷与登录鉴权、企业与邀请码绑定、无邀请码账户 `used + in_flight < 5` 短事务预占与成功实扣/失败回滚、跨企业 SQL 强隔离与管理员视图；
   - 实现服务端批量上传、`PENDING → INDEXING → APPROVED / PARSE_FAILED` 及 `REJECTED` 五态流转、同企业重复 MD5 幂等去重、6 项必记台账字段与服务端可视化规则配置后台。
   - **放行条件**：多角色越权测试 0 泄漏，10 路并发下 5 次限额无穿透且损坏件回滚准确，`PENDING` 与 `PARSE_FAILED` 模型 0 混入对比池。
4. **阶段 4：三维图形化对比工作台集成、客户端双 API 与整机联调交付（约 2.5–3 周，双人联调交付，对应报价模块三 24 人/天）**
   - 集成服务端 WebGL/Three.js 并排联动与双色叠加对比工作台、固定工程边界提示、多维有效权重得分详情弹窗与选中次数回写；
   - 交付禁 URL 传密、日志脱敏、带限流防爆破的客户端批量上传 API 和客户端单件 STP 对比检查 API，提供接口文档与调用示例，在目标环境完成压力、安全与验收测试。
   - **放行条件**：按「建议验收口径与统计分母」逐项核验通过，输出联调验收报告与部署运维手册。

## 明确不做

- **不做自动工程替代放行与合规签批**：系统输出相似度分数、模型名称及几何/属性差异明细，界面固定提示不自动出具“可直接替代生产、公差/载荷/装配干涉已合格”的工程放行结论。
- **不做中性 STEP 到原生 CAD 参数化特征树的逆向重建**：不从 `.stp` 逆向恢复 SolidWorks/NX/Creo 的草图约束、建模历史步骤或自定义方程变量名。
- **不做未约定的外部业务系统深度集成**：首期不包含与客户 ERP、PDM/PLM、MES 或企业微信/AD 域单点登录的双向自动对接（客户端按客户要求通过 HTTPS Header/Body 携带用户名密码或短期 Token 调用标准接口）。
- **不做大型整机装配体自动拆件配准与深度学习训练平台**：首期针对零件级 STEP 模型；整装配层级自动配准或 AI 神经网络训练不在本次报价与工期范围内。
